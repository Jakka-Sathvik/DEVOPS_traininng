6. Create a Metric Filter

CloudWatch Logs can convert matching log events into a CloudWatch metric.

Architecture:

CloudWatch Log Event
        │
        │ contains "ERROR"
        ▼
   Metric Filter
        │
        ▼
Custom Metric

Example filter pattern:

ERROR

The filter searches log events for the word:

ERROR

Every matching log event can increment the metric.

7. Custom Metric

Create a custom metric such as:

Namespace:
DevOps/Application

Metric Name:
ApplicationErrors

Example:

DevOps/Application
        │
        └── ApplicationErrors

Metric meaning:

ApplicationErrors = Number of application error log events

For example:

ApplicationErrors = 0

means no matching errors were detected during the period.

If an application error occurs:

ApplicationErrors = 1

or more.

8. Create CloudWatch Alarm

Create an alarm using:

Metric:
ApplicationErrors

Example alarm configuration:

Metric:
ApplicationErrors

Statistic:
Sum

Period:
5 minutes

Threshold:
>= 1

Evaluation:
1 out of 1 datapoints

The logical condition is:

IF ApplicationErrors >= 1
THEN
    Alarm = ALARM
9. Alarm States

CloudWatch alarms normally have three states:

OK
ALARM
INSUFFICIENT_DATA
OK

No application errors were detected.

ApplicationErrors = 0

Alarm:
OK
ALARM

At least one application error was detected within the configured evaluation period.

ApplicationErrors >= 1

Alarm:
ALARM
INSUFFICIENT_DATA

CloudWatch does not have enough data to determine the alarm state.

Metric data unavailable

Alarm:
INSUFFICIENT_DATA

18. Key Concepts Learned
Application Logs

Application logs provide detailed information about what happened inside the application.

CloudWatch Logs

CloudWatch Logs stores and provides access to application and infrastructure logs.

Metric Filter

A metric filter searches log events and converts matching events into metric data.

CloudWatch Metric

A metric provides numerical information that CloudWatch can monitor.

CloudWatch Alarm

An alarm evaluates a metric against a configured threshold.

Incident Detection

An alarm entering the ALARM state can be used as an indication that an application problem requires investigation.
